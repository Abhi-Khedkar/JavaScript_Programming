🚀 **How to Run**
All programs are written in standard JavaScript and can be executed using Node.js via the terminal.

1. **Open your terminal** and navigate to the specific folder (e.g., a specific day in DailyWork):
   ```bash
   cd DailyWork/Day_01
   ```

2. **Execute the JavaScript file** using Node (replace with the actual file name, e.g., program130.js):
   ```bash
   node program130.js
   ```
